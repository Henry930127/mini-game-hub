# Legacy Express Backend

此目錄是 Mini Game Hub 遷移至 Firebase 前使用的 Express + MySQL 後端。

## 狀態

- 已封存，不是目前的 production backend。
- Firebase Hosting 不會部署或執行此目錄。
- 現行網站不會呼叫此目錄提供的 REST API。
- 帳號、資料與權限目前由 Firebase Authentication、Cloud Firestore 與 Firestore Security Rules 負責。

此程式碼僅保留作為歷史參考。除非決定放棄 Firebase 架構並重新導入伺服器與 MySQL，否則不應啟動、部署或新增功能到此目錄。
